# SkillUp Coach

Telegram-бот **@SkillUpCoachBot** — коуч для профессионального роста IT-специалистов.

Помогает прокачивать один навык за месяц маленькими шагами: каждый день — один шаг по выбранному навыку (теория, практика, общение или рефлексия). Бот ведёт серию, считает успехи и раз в неделю присылает дайджест с прогрессом.

## Проблема

Джуниоры и мидлы в IT хотят развиваться, но из-за ежедневной загрузки откладывают самообразование. Через месяц обнаруживают, что не прогрессируют — и это вызывает выгорание.

## Решение

Бот фиксирует **один навык** на месяц и просит делать **один маленький шаг** в день. Серия успешных дней и очки мотивируют не прерываться. Раз в неделю — дайджест с прогрессом и советом.

## Функционал

- Онбординг с выбором навыка
- Утренний вопрос: какой шаг ты сделаешь сегодня?
- Вечерний чекап: получилось ли?
- Серия (streak) и очки за успехи
- Еженедельный дайджест
- Команды `/stats`, `/settings`, `/help`

## Стек

- **Язык:** Python 3.10+
- **Библиотеки:** aiogram 3.x, APScheduler, aiosqlite
- **БД:** SQLite
- **Хостинг:** Railway
- **CI/CD:** GitHub

## Запуск локально

1. Клонировать репозиторий
2. Создать виртуальное окружение:
python -m venv venv
venv\Scripts\activate # Windows
source venv/bin/activate # Mac/Linux
3. Установить зависимости:
pip install -r requirements.txt
4. Создать `.env` на основе `.env.example` и вписать токен бота
5. Запустить:
python main.py
