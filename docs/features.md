# Функции SkillUp Coach

## Обязательные для MVP
1. Выбор навыка (кнопки + «Другое»).
2. Утренний вопрос: выбор типа шага (теория/практика/общение/рефлексия).
3. Вечерний чекап: «Да / Нет / Перенесу».
4. Серия (streak) — количество дней подряд.
5. Очки за каждый выполненный шаг.
6. Еженедельный дайджест (статистика + совет).
7. Команда /stats — прогресс по запросу.
8. Настройка времени уведомлений.
9. Хранение истории в SQLite.

## Желательные
10. Дневник шагов (опционально, что именно сделано).
11. Самооценка уровня навыка раз в 2 недели.
12. Цель на месяц с прогрессом.
13. Связь с реальной работой (применил / пока нет).
14. Экспорт достижений для резюме.
15. День отдыха без сброса серии.

## После MVP
16. Персональные рекомендации (материалы, курсы).
17. Командные челленджи.
18. Интеграция с календарём.
19. Экспорт в Notion / Google Sheets.
20. Уровни (Новичок → Продвинутый → Эксперт).

## Приоритеты

| Приоритет | Функции |
| :--- | :--- |
| Обязательно | 1–9 |
| Желательно | 10–15 |
| После MVP | 16–20 |
