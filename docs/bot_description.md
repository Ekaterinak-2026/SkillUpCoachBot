# SkillUp Coach — описание бота

**Username в Telegram:** @SkillUpCoachBot
**Название:** SkillUp Coach

## Короткое описание (About, до 120 символов)
Коуч для карьерного роста. Один навык, один шаг в день. Серия, успехи, отчёт с прогрессом.

## Полное описание (Description, до 512 символов)
Каждый день — маленькая инвестиция в карьеру. SkillUp Coach: один навык, один шаг в день — теория, практика или общение. Я веду серию, считаю успехи и присылаю отчёт с прогрессом. Для IT-специалистов, которые хотят расти в должности и доходе.

## Команды
- /start — Начать и выбрать навык
- /stats — Мой прогресс
- /settings — Настроить время напоминаний
- /help — Помощь

## Приветствие после /start
Привет! Я SkillUp Coach 👋

Помогу тебе прокачать один навык за месяц — без перегруза и выгорания. Каждый день один маленький шаг: теория, практика или общение. Я веду серию, считаю успехи и присылаю отчёт с прогрессом.

Это инвестиция в твою карьеру. Давай начнём — какой навык прокачиваем?

## Принципы
- Один навык на месяц — фокус без распыления.
- Один шаг в день — низкий порог входа.
- Серия и очки — геймификация без давления.
- Позитивный тон, никаких упрёков.
